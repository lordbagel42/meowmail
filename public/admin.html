Connect your workspace

Credentials are entered privately here, encrypted in backend storage, and never returned. Leave a secret blank to keep its saved value.

  1. Create a Slack app from the manifest.

    Open app manifest JSON ↗, then create an app ↗ and choose “From a manifest”. The manifest intentionally omits the event request URL: save the signing secret here before Slack verifies that endpoint. The interaction URL is this site's origin followed by /slack/interactions.

  2. Install the app and invite it to #meow-mail.

    Copy the bot token and signing secret from Slack. Save both here with the channel ID, not the channel name. Leave “Allow new temporary addresses” OFF during this step.

  3. Configure Slack events after saving credentials.

    In the Slack app's Event Subscriptions, set the request URL to this site's origin followed by /slack/events. Enable events and subscribe to the bot event message.channels. Reinstall the app if Slack asks.

  4. Connect review services, then enable Meow Mail.

    Save a Tavily API key and connect your own Codex subscription below, then turn on “Allow new temporary addresses” and save. First enablement automatically queues the welcome announcement and ban-list pin. The bot asks users to accept terms when they request an address. Use the button below only to repost or update the welcome.

Codex subscription

Connect your own account using the legacy Codex browser callback flow, not someone else's account. Pi uses openai-codex / gpt-6.1-terra and consumes your subscription allowance; there is no paid API fallback. Tavily still requires a separate API key.

The backend stores the grant encrypted. Access and refresh tokens never return to this browser. The backend validates state and PKCE using one-time encrypted pending state. Each Connect/Reconnect starts a fresh 10-minute flow.

Open OpenAI sign-in in a new tab ↗

After approving, OpenAI redirects to http://localhost:1455/auth/callback. The local page may fail to load; that is expected. No local listener is required on your machine. Copy the full callback URL from that tab's browser address bar and paste it only into this owner-protected dashboard, never into the conversation thread, Slack, or another site.
